// WHAT IT GIVES YOU

它多做的六件事

逐用例全量反馈

不只告诉你「错了」，而是把每个用例的输入、你的输出、期望输出、耗时与峰值 RSS 逐行列出来。错误边界一眼可见 —— 这是刷题时最需要、也最难自己造出来的信息。

草稿永不掉

输入停顿 0.8 秒就自动存草稿，切题、刷新、关浏览器都在；多标签页同时改同一题会先问你再覆盖。

执行是真隔离

fork + setrlimit：CPU 时间与地址空间都有硬上限，2 核 2G 也跑得动。

架构本身能讲

测试程序生成器、逐用例 fork 执行、线程池 + 全局闸门、声明式角色 —— 每一条都能在面试里讲成一分钟的故事。

  • 题库 JSON 是唯一真源，启动时同步入库
  • 用户代码与题库 harness 物理隔离
  • 并发参数按实测机器算，不按经验值抄
  • 数据全部留在本机，断网也能刷题

异步 + 轮询

提交立刻返回 id，前端每 1.5 秒拉一次结果，并告诉你「前面还有 N 个评测」。刷新页面会自动恢复轮询。

找得到、复盘得了

按关键词、难度、算法标签、来源标签、我的进度组合筛选；同题两次提交可并排 diff，一键回填编辑器。

// WHAT HAPPENS ON SUBMIT

一次提交，走了哪五步

  1. 01 入队 写一条 pending 记录，返回 id 与队列位置，不阻塞请求
  2. 02 编译 g++ -c user.cpp，再链接题库生成的 tester —— 题库代码永不被改动
  3. 03 逐用例执行 每个用例一次 fork，套 CPU / 内存 / 文件大小三重 rlimit
  4. 04 解析协议 harness 按 @@OJ@@ 协议回报结果，一条也没有就判平台错误
  5. 05 写回 单事务写入逐用例明细与汇总列，前端下一次轮询就能渲染出表格

// QUESTIONS

常见问题

必须注册才能看题吗？

不必。未登录可以打开任意题目的完整题面与提示，只是不能提交、不能收藏、看不到自己的统计。

代码会被拿去做什么？

只在你自己这台机器上编译与执行。SQL 全部走预处理语句，管理员角色由 .env 的名单决定，页面不提供任何提权操作入口。

2 核 2G 的机器真的跑得动吗？

跑得动，但吞吐有限：判题并发闸门是 4，且并发参数是按实测内存算过的 —— 卡住的往往不是 CPU 而是内存。

改了题库会怎样？

改 problems/*.json 后重启即可。历史提交保存的是当时的输入/输出快照，所以改题不会让旧记录凭空少行。

支持哪些语言？

首版只支持 C++（g++ 12 / C++17 / -O2 -Wall）。多语言执行是明确列出的非目标。

管理面板

管理能力当前是严格只读的，且只有一个 API 端点。页面尚未实现（T4.14）。

GET /api/admin/overview —— 需要 role = "admin"； 未登录回 1002，非管理员回 1003。 管理员身份只能通过改 .env 的 OJ_ADMIN_USERNAMES 再重启获得， 页面与 API 都不提供提权入口（SPEC §6.3.1）。 



      
或者直接用 curl：

      
curl -c /tmp/oj.jar -X POST http://127.0.0.1:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}'
curl -b /tmp/oj.jar http://127.0.0.1:8080/api/admin/overview
